# PROMINA — برومينا للدعاية والإعلان

موقع تفاعلي مستقل، مبني بهوية برومينا، مع معرض مشاريع بإطارات متحركة وفلاتر، ومتجر وحاسبة مقاسات وطلبات عروض أسعار.

## معاينة فورية
افتح `index.html` مباشرة في المتصفح؛ يحتوي جميع الصور والرسوم داخل الملف نفسه. يتطلب اتصال إنترنت فقط لتنزيل خط Cairo من Google Fonts؛ مع خط احتياطي محلي.

## نشر مجاني مستقل عبر GitHub Pages
1. أنشئ مستودعًا **عامًا** منفصلًا اسمه `promina-showcase`.
2. ارفع ملف `index.html` إلى جذر المستودع.
3. Settings → Pages → Deploy from branch → main → / (root).
4. رابط المعاينة المتوقع: `https://USERNAME.github.io/promina-showcase/` بعد تفعيل Pages.

لا تستخدم النطاق `crispy-c.com` أو مستودع Crispy Cut.

## جهات التواصل
في `window.PROMINA_CONFIG` أضف رقم واتساب حقيقيًا أو بريد مبيعات حقيقيًا بعد التحقق، ثم اربط الاستقبال بالخادم عند الحاجة. هذه نسخة تفاعلية لأخذ الطلبات، وليست بوابة دفع.
